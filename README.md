# Trust-and-safety-content-moderation-analysis
Trust &amp; Safety Content Moderation Analytics Dashboard built in Excel to analyze 24,783 content records, monitor policy violations, escalation trends, moderator performance, and compliance metrics through interactive KPI reporting and visualisations.
Developed an end-to-end Excel dashboard using a content moderation dataset containing 24,783 records. The project focuses on analyzing hate speech, offensive content, review outcomes, escalation rates, moderator performance, and policy compliance metrics.
Key Features:
Interactive KPI dashboard for Trust & Safety operations
Content category distribution analysis
Review outcome tracking (Approved, Rejected, Escalated)
Moderator-wise performance monitoring
Priority-based content analysis
Monthly moderation trend reporting
Escalation and compliance rate calculations
Pivot Tables, Pivot Charts, Slicers, and Advanced Excel formulas
Tools Used:
Microsoft Excel
Pivot Tables
Pivot Charts
Conditional Formatting
KPI Reporting
Data Validation
Business Impact: Enabled data-driven monitoring of moderation workflows, identification of high-risk content categories, and performance tracking to support Trust & Safety reporting and operational decision-making.
